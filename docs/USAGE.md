# 使用指南

本文档介绍两个功能模块的完整操作流程、输出规则与注意事项。

---

## 1. 界面与引擎状态

启动后左侧是工具导航，底部显示引擎状态：

- **FFmpeg 6.0 就绪**：内置引擎可用。
- **Apple VideoToolbox 加速 / NVIDIA NVENC 加速 / …**：检测到了可用的硬件编码器。
- **软件编码模式**：你在设置里关闭了硬件加速，或没有检测到硬件编码器。
- **引擎不可用**：通常是自定义 FFmpeg 路径错误，进入 **设置 → FFmpeg 路径** 恢复内置版本。

第一次打开应用时，主进程会用一段极小的测试视频实际验证硬件编码器，因此状态可能延迟 1–3 秒出现。检测结果会缓存，直到你点击“重新检测”或更换 FFmpeg 路径。

## 2. 视频去水印（核心功能）

### 2.1 选择视频

- 点击 **选择本地视频**，或将视频拖入上传区域。
- 一次处理一个视频。选择多个时只使用第一个。
- 支持常见容器：MP4 / MOV / M4V / WebM / MKV / AVI / FLV / WMV / TS / M2TS / 3GP / OGV 等（取决于 FFmpeg 解码能力）。
- 建议先确认视频能在系统播放器中正常播放；若仅预览失败，处理通常仍可继续。

### 2.2 定位水印画面

- 使用底部进度条拖动到水印最清晰的一帧。
- **播放 / 暂停** 按钮用于检查动态效果。
- **−1 帧 / +1 帧** 按视频实际帧率步进，便于精确定位。
- 时间显示格式：`分:秒`，超过一小时显示 `时:分:秒`。

### 2.3 框选区域

- 在画面上按住鼠标拖拽，即可创建一个矩形区域。
- 最多 **8 个区域**。
- 点击区域可以选中；选中后：
  - 拖动区域内部：整体移动。
  - 拖动四角圆点：调整宽高。
- 右侧列表会显示每个区域的宽高与位置（按画面百分比显示），可单独删除或清空全部。
- 创建时如果区域小于 14px，会自动丢弃。

区域坐标以画面归一化比例保存，因此预览缩放、窗口大小变化都不会影响最终处理位置。

### 2.4 选择遮挡方式

| 方式 | 效果 | 适用场景 |
| --- | --- | --- |
| **模糊** | 高斯模糊，边缘柔和 | 希望观感自然、不明显“打码” |
| **马赛克** | 像素块放大，遮盖彻底 | 需要明显遮挡或覆盖较大区域 |
| **纯色** | 用纯色块完全覆盖 | 大面积水印、角标、台标 |

**强度（1–10）：**

- 模糊：高斯 `sigma` 按区域短边计算，公式为 `shortSide × (0.02 + strength × 0.03)`，上限 40。
- 马赛克：块大小按区域短边计算，`shortSide × (0.04 + strength × 0.03)`，最小 4px。
- 强度和区域大小共同决定视觉效果；同样的强度，大区域看起来会更明显。
- 预览与最终导出使用完全相同的公式。

**纯色模式** 可选择一个十六进制颜色，默认黑色 `#000000`。

### 2.5 输出质量

- **精细**：`libx264 -preset veryfast -crf 20`（源码率未知时），画质优先。
- **标准**：`libx264 -preset ultrafast -crf 23`，速度优先。
- 如果成功读取到源视频的视频流码率，会优先使用该码率 + VBV 约束，尽量让成片体积接近原片；此时两种档位的差别主要体现在编码 preset。
- 音频：AAC / MP3 / AC3 / EAC3 / ALAC 直接 stream copy；其他编码转 AAC（96–320kbps，跟随源码率）。

### 2.6 编码引擎

右侧 **编码引擎** 区域显示当前策略，并提供开关：

- **开启**：优先使用 GPU / 媒体引擎（macOS VideoToolbox、NVIDIA NVENC、Intel Quick Sync、AMD AMF）。
- **关闭**：始终使用 `libx264`。
- 任务开始后修改开关，会在**下一次处理**生效。
- 硬件编码失败时，任务会自动回退到软件编码，并在进度说明中提示。

> 硬件编码速度快，但在极低码率下画质可能略逊于 `libx264`，且不同显卡的码率控制存在差异。对画质有严格要求时，可以关闭硬件加速并使用“精细”档。

### 2.7 开始处理

1. 点击 **一键处理**。
2. 选择输出路径（默认 `视频去水印_YYYYMMDD-HHmm.mp4`）。
3. 观察进度；可随时取消。
4. 完成后可预览、在文件夹中显示、用系统播放器打开，或 **调整后重新处理**。

输出保持原视频分辨率与帧率，不做缩放；奇数宽高会自动裁剪到偶数，以满足 yuv420p 色度抽样要求。

### 2.8 预览说明

- 预览由 Canvas 2D 在暂停帧或播放过程中实时绘制。
- 如果视频编码不受 Chromium 支持，会出现“预览不可用”提示，但你仍然可以盲选区域并处理（建议先用系统播放器确认水印位置）。
- 极少数情况下自定义协议会触发安全策略，应用会自动切换兼容模式；如果画面仍为空白，处理功能不受影响。
- 预览会限制绘制频率（约 30fps），避免占用过多 CPU。

### 2.9 去水印限制

- 这是**遮挡**，不是 AI 内容修复。它不会还原水印下面的画面。
- 水印如果整段移动、缩放或时隐时现，单个矩形可能无法覆盖所有位置；可以添加多个区域，或选择更大的区域。
- 最多 8 个区域；区域必须为轴对齐矩形，不支持任意多边形或旋转框。
- 处理时会对整段视频重新编码（无法只修改局部帧且保持原码流）。
- HDR / 10-bit 输入会转换为 8-bit `yuv420p`，HDR 元数据不会保留；如果需要保留 HDR，请等待后续版本或使用专业工具。

## 3. 视频拼接

### 3.1 添加素材

- 点击左侧或右侧的 **选择本地视频** / **添加视频** 按钮。
- 或者把一个或多个视频文件拖进上传区域。
- 支持 **2–6 段**。超出部分会提示并忽略。
- 添加后会立即用 ffprobe 读取时长、分辨率、大小、编码格式；读取失败的素材会被移除并提示原因。
- 队列中允许出现同一个文件多次（例如 A-B-A），重复素材只会转码一次。

> 预览缩略图使用 Chromium 内置解码器。MKV、部分 AVI/HEVC 文件可能显示“无法预览”，但这**不影响**拼接，因为实际处理由 FFmpeg 完成。

### 3.2 调整顺序

- 使用每条素材右侧的 **↑ / ↓** 调整顺序。
- 使用 **删除** 移除单条，或 **清空** 清空队列。
- 拼接顺序就是从下到上的队列顺序。

### 3.3 开始拼接

点击 **开始拼接** 后：

1. 弹出系统保存对话框，选择输出路径与文件名（默认 `视频拼接_YYYYMMDD-HHmm.mp4`，上次使用的目录会被记住）。
2. 应用先逐个探测素材，再决定处理策略。
3. 处理过程中显示阶段、百分比与取消按钮。
4. 完成后可直接预览，或 **在文件夹中显示** / **播放** / **再拼一次**。

处理期间不能修改队列；取消会终止 FFmpeg 并清理中间文件，目标文件不会被写坏。

### 3.4 两种处理策略

| 条件 | 策略 | 速度 | 画质 |
| --- | --- | --- | --- |
| 全部为 H.264，分辨率、像素格式、帧率、旋转、音轨参数一致 | `concat` + `stream copy` | 极快（秒级） | 与原片完全一致 |
| 任意一项不一致（含横竖屏混合、有无音轨） | 逐段标准化后 `stream copy` 合并 | 需要转码，较慢 | 统一画布后重新编码 |

**标准化规则：**

- 输出方向跟随第一段视频。
- 画布限制：横屏最大 1280×720，竖屏最大 720×1280；小于该尺寸时保持原尺寸。
- 每段等比缩放并补黑边，不拉伸画面。
- 统一为 `30fps`、`yuv420p`、H.264；音频统一为 `AAC 44.1kHz 立体声 128kbps`。
- 没有音轨的素材会自动补一条静音音轨，保证所有片段结构一致。

**输出文件：** MP4（H.264 / AAC），带 `+faststart`，适合网页播放与常见播放器。

### 3.5 拼接限制

- 单次 2–6 段。
- 输出固定为 MP4；不支持直接输出 MKV/WebM。
- 标准化路径会把帧率统一到 30fps。如果需要保留 60fps 或高分辨率，请确保素材参数一致以走无损路径。
- 素材超过 2GB 会提示处理时间较长，但不会阻止处理。

## 4. 输出与临时文件

- 输出文件名默认带日期时间，避免覆盖；你也可以在保存对话框中自由修改。
- 所有输出先写入**同目录下的隐藏临时文件**，成功后原子替换目标文件：
  - 取消或失败：不会破坏原有的同名文件。
  - 成功：旧文件（如果存在并确认覆盖）才会被替换。
- 转码中间文件位于系统临时目录（以 `local-video-lab-` 开头），任务结束会自动删除；异常退出留下的目录会在下次启动 24 小时后清理。
- 设置页提供 **清理临时文件** 按钮（有任务运行时不可用）。

## 5. 性能建议

- **优先开启硬件加速**：macOS 的 VideoToolbox 与 Windows 的 NVENC/Quick Sync 能显著缩短编码时间。
- **参数一致的素材优先走无损拼接**：同机位、同编码参数拍摄的素材通常可以直接 stream copy。
- **避免在处理时让电脑进入睡眠**：睡眠会暂停所有进程；建议接通电源并保持唤醒。
- **使用 SSD**：素材读取和临时文件写入都依赖磁盘速度。
- **长视频先试短片**：先用 10–30 秒片段确认区域与强度，再处理完整视频。

在 Apple Silicon 测试机上，对一段 23.75 秒、1152×720 的视频执行去水印（2 个区域、VideoToolbox）约需 1 秒；同一段视频复制两份做无损拼接约需 0.04 秒。实际速度取决于硬件、素材与编码参数。

## 6. 数据存储位置

应用只保存少量偏好设置（自定义 FFmpeg 路径、硬件加速开关、最近输出目录）：

| 平台 | 路径 |
| --- | --- |
| macOS | `~/Library/Application Support/Local Video Lab/settings.json` |
| Windows | `%APPDATA%\Local Video Lab\settings.json` |

设置页底部会显示实际数据目录。删除该目录即可恢复默认设置。
